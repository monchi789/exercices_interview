# 1️⃣ Pipeline CI/CD para API Python

### Problema

Configurar un pipeline que:

1. ejecute **tests**
2. construya **imagen Docker**
3. suba imagen a **Docker Hub**
4. despliegue automáticamente en un **VPS**

### Evaluación

* CI/CD
* Docker
* automatización de despliegues

### Tecnologías sugeridas

```
GitHub Actions
Docker
SSH deploy
```
