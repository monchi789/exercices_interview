# 1️⃣ API agregadora de usuarios (similar a tu ejemplo)

Crear una API que consuma:

```
https://randomuser.me/api
```

y devuelva:

```
15,000 usuarios únicos
```

### Requisitos

* respuesta < **3 segundos**
* eliminar duplicados
* devolver solo campos:

```
gender
first_name
last_name
email
uuid
age
```

### Habilidades evaluadas

* concurrencia
* optimización
* APIs externas
