# 8️⃣ Automatización de migración de archivos

### Problema

Migrar archivos de una carpeta local a un almacenamiento remoto.

El script debe:

1. detectar archivos nuevos
2. subirlos
3. verificar integridad
4. moverlos a carpeta `processed`

### Habilidades

* automatización de pipelines
* manejo de errores
