# 2️⃣ Monitor de estado de servicios

### Problema

Crear un script que monitoree cada **30 segundos** si los siguientes servicios están activos:

* API backend
* Base de datos
* Redis

Si uno falla:

* guardar log
* enviar alerta por email o Slack.

### Habilidades

* requests
* monitoreo
* manejo de errores
