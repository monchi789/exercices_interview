# 5️⃣ Automatización de descarga masiva

### Problema

Dada una lista de URLs en un archivo:

```
urls.txt
```

Crear un script que:

1. Descargue todos los archivos
2. Los guarde en una carpeta
3. Maneje errores
4. Descargue **en paralelo**

### Habilidades

* concurrencia
* requests
* asyncio
